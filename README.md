# E-Commerce Sales Analytics Dashboard

## Project Overview
This is a Power BI portfolio practice project focused on analyzing e-commerce sales performance and generating business insights.

## Dashboard Preview
![E-Commerce Sales Analytics Dashboard](./Dashboard/Ecommerce_Sales_Dashboard.png)

## Business Objectives
- Analyze overall sales and order performance.
- Identify top-performing products and categories.
- Compare sales across cities.
- Understand payment methods and order statuses.
- Highlight business opportunities using key insights.

## Key Performance Indicators (KPIs)
- Total Orders
- Total Sales
- Total Quantity
- Delivered Orders
- Cancelled Orders

## Tools Used
- Microsoft Power BI
- Microsoft Excel (for data, if applicable)

## Dashboard Features
- Monthly Sales Trend
- Sales by Category
- Sales by City
- Order Status Analysis
- Top 5 Products by Sales
- Payment Method Analysis
- Key Business Insights

## Project Files
- `Dashboard/`: Dashboard screenshot
- `PowerBI/`: Power BI report file
- `Data/`: Dataset used in the analysis
- `Documentation/`: Project documentation

## Learning Outcomes
- Building interactive Power BI dashboards
- Creating KPIs and charts
- Analyzing sales and customer-related metrics
- Communicating business insights visually

## Disclaimer
This is a portfolio practice project for learning and demonstration purposes. Please verify the dataset and figures before using them for business decisions.
