# E-Commerce Sales Analytics Dashboard | Power BI
## 1. Project Overview

This project is an interactive E-Commerce Sales Analytics Dashboard developed using Microsoft Power BI to analyze sales performance and business operations for an online store in Pakistan.
The dashboard provides a comprehensive overview of sales, orders, product performance, customer purchasing trends, payment methods, and order status. It helps transform raw sales data into meaningful business insights through interactive visualizations, KPI cards, charts, and filters. This is a practice project created to improve my skills in data analysis, business intelligence, data visualization, and dashboard development.


## 2. Project Objectives

The main objectives of this project are:

- Analyze overall e-commerce sales performance.
- Monitor total orders, sales, and quantities.
- Identify monthly sales trends and patterns.
- Compare sales performance across product categories.
- Analyze city-wise sales performance.
- Identify the top-performing products and categories.
- Understand order status and delivery performance.
- Analyze customer payment method preferences.
- Identify business opportunities through key insights.
- Support better business decisions using data visualization.

## 5. Interactive Dashboard Filters

The dashboard includes the following filters:

- **Date:** Filter the analysis by date.
- **City:** View results for selected cities.
- **Category:** Analyze specific product categories.
- **Payment Method:** Compare selected payment methods.
- **Order Status:** Filter orders by their current status.

These filters allow users to explore the data according to their requirements and analyze different aspects of business performance.

## 6. Key Business Insights

The dashboard highlights the following insights, as displayed in the screenshot:

- **Highest Sales City:** Faisalabad, with sales of PKR 7,755,000.
- **Top Performing Category:** Electronics, contributing 70% of total sales.
- **Most Used Payment Methods:** Cash and Credit Card, with displayed shares of 34% and 18%.
- **Top Performing Product:** Laptop, with a displayed value of 4,950K.
- **Lowest Performing City:** Rawalpindi, with a displayed value of 0.31%, compared with Sialkot at 1.37%.

These insights help identify strong-performing areas and potential opportunities for further investigation.
